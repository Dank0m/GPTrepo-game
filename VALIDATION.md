# Проверка Frontier

Проверено в текущей облачной машине 24 октября 2026 года. Код ещё не отправлен
в GitHub и не развёрнут на публичном сервере. Восстановление в новой задаче
после публикации среды отдельно не проверялось.

## Результаты

- Node.js 24.19.0, npm 12.1.0; зависимости установлены через `npm run inst`
  с сохранением lockfile, проверки целостности и ограничений `.npmrc`.
- `npm run typecheck`: успешно для корневого проекта и всех пакетов.
- `npm run build-prod`: успешно; созданы клиент, Web Worker, хешированные
  ресурсы и `asset-hashes.json`. Предупреждения о размере JS-бандлов не блокируют
  сборку.
- Клиент и локальные игровые процессы запущены через `npm run dev:host`.
  Запрос `/api/health` через клиентский сервер вернул HTTP 200 и `status: ok`.
- Браузерная одиночная партия: карта 2000 × 1000, 13 живых участников;
  после выбора стартовой точки симуляция продвинулась с тика 6 до 92,
  войска выросли с 25 330 до 52 174, золото со 100 до 8 700. Клик по соседней
  нейтральной территории увеличил владения с 52 до 404 клеток.
- Приватное сетевое лобби создано через интерфейс; второй независимый браузер
  перешёл по реальной ссылке комнаты, и хозяин получил двух участников через
  WebSocket. Совместное прохождение полного сетевого матча не проверялось.
- Создание лобби осталось доступным после повторных ошибок необязательного
  локального API аккаунтов. Ошибок JavaScript в стабильной одиночной партии
  после исправления совместимости Keyboard API не было.

## Тесты

Первый полный прогон `npm test -- --maxWorkers=4` завершился за 538 секунд:
667 файлов прошли, 5 файлов содержали ошибки; 9 526 тестов прошли,
6 завершились ошибкой и 1 был пропущен. Он выполнялся одновременно с адаптацией
копии, поэтому часть результатов относится к промежуточным версиям файлов.

Все шесть обнаруженных ошибок разобраны и проверены повторно:

- В Chromium Keyboard API не всегда имеет `addEventListener`: добавлена
  проверка поддержки и регрессионный тест.
- Ожидания заголовка и метаданных приведены к названию Frontier; ключ перевода
  исходного названия сохранён в ссылке на проект-источник.
- Тест серверного HTML теперь учитывает фактический манифест ресурсов после
  production-сборки, сохраняя проверки структуры вывода.
- Тест подписки исходного проекта обращался к незамоканному `api.test`:
  ошибка подтверждена на неизменённом upstream. Добавлен локальный тестовый
  каталог; проверки поведения платежей сохранены.

После последних изменений повторно выполнены **176 тестов в 7 файлах — все
прошли**: `KeybindLabels`, `MainInitialize`, `ServerList`,
`LangSelectorTranslate`, `CosmeticsPaymentsMigration`, `RenderHtml`,
`TranslationSystem`. Проверены также отключение рекламы и отсутствие блокировки
локальной игры необязательным API при сохранении защиты для явно заданного API.
Полный набор из 672 файлов после этих исправлений повторно не запускался.

## Ограничения

- Браузерная автоматизация использовала SwiftShader без аппаратного GPU и
  тестовую подмену имени рендерера, как в headless-тестах upstream. Реальный
  WebGL-рендеринг и игровой движок работали; производительность аппаратного
  GPU не проверялась. Проверка поддержки GPU в самой игре сохранена.
- Закрытый API OpenFront для аккаунтов, покупок и рейтингового подбора не входит
  в исходный пакет. Для локальных анонимных партий он не требуется.
- Лицензии, ограничения ресурсов и уведомления авторов сохранены. Для публичного
  размещения необходимо предоставить соответствующий исходный код; ссылка в
  интерфейсе указывает на `Dank0m/GPTrepo-game` и заработает после публикации кода.

Команды установки и запуска сохранены в черновике конфигурации среды.
Это не публикует среду и не сохраняет живые процессы между задачами.
